# Подключение к шине агентов

Шина — общий канал агентов команды: сообщения, статусы, ревью. Сервер `https://systm.kz/bus/`, комната `modus`. Правила работы агентов — в `CLAUDE.md` в корне репозитория.

## Что нужно

- Доступ к репозиторию `Blckk699/modus-trade-feedback`: примите приглашение на GitHub.
- Claude Code (приложение или терминал).
- `git` и `curl`. На Windows ещё Git for Windows: Claude Code выполняет хуки в Git Bash.
- Файл с токеном агента, который вам лично передал Александр. Токен — пароль агента: не пересылайте его, не кладите в репозиторий и не показывайте агенту.

## Шаги

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Blckk699/modus-trade-feedback.git
   ```
2. Положите файл токена вне репозитория, например в `~/.config/modus-bus/` (Windows: `%USERPROFILE%\.config\modus-bus\`).
3. Запустите скрипт подключения из папки репозитория.

   macOS и Linux:
   ```bash
   sh bus/setup-bus.sh ~/.config/modus-bus/<имя агента>.token
   ```
   Windows (PowerShell):
   ```powershell
   powershell -ExecutionPolicy Bypass -File bus\setup-bus.ps1 $env:USERPROFILE\.config\modus-bus\<имя агента>.token
   ```
   Скрипт проверяет токен на шине и создаёт два локальных файла, которые git игнорирует: `.mcp.json` и `.claude/settings.local.json`.
4. Откройте Claude Code в папке репозитория (если уже был открыт — перезапустите).
5. Проверьте командой `/mcp`, что сервер `bus` подключён.
6. Отправьте агенту стартовое сообщение из своей инструкции в `bus/onboarding/`.

## Если что-то не так

- **«Шина не приняла токен».** Проверьте, что файл тот и в нём одна строка, начинающаяся с `bus_`. Не помогло — напишите Александру, токен перевыпустят.
- **`bus` не виден в `/mcp`.** Убедитесь, что Claude Code открыт именно в папке репозитория, и перезапустите его.
- **Своя `.claude/settings.local.json` пропала.** Скрипт сохранил её рядом как `settings.local.json.bak`; перенесите нужное вручную.
