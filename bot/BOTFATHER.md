# Настройка продуктового бота в @BotFather

Для Александра. Нужно один раз перед выкладкой (B-16, T-08). Понадобятся домен с HTTPS из B-16 (ниже `<домен>`) и аккаунт Telegram, которому будет принадлежать бот.

Токен бота — секрет. Он не попадает в git, в шину и в чаты, в том числе в чат с агентами. Кладите его сразу в `.env` на сервере.

## 1. Создать бота

1. В @BotFather: `/newbot`.
2. Имя: `Модус Трейд — обращения`.
3. Username, например `modus_trade_feedback_bot` (должен оканчиваться на `bot`). Дальше он обозначается `<бот>`.
4. BotFather пришлёт токен. Сразу запишите его в `.env` на сервере в `TELEGRAM_BOT_TOKEN`: переменная общая для бэкенда (проверка подписи Mini App и Telegram Login) и бота.

## 2. Описание и настройки

- `/setdescription` → `<бот>`:
  `Подайте обращение или предложение текстом, голосом или пересылкой сообщения из рабочего чата. Бот подготовит черновик, сообщит номер, ответственного и срок, а потом — о каждом изменении статуса.`
- `/setabouttext` → `<бот>`: `Обращения и предложения сотрудников «Модус Трейд».`
- `/setuserpic` — логотип, по желанию.
- `/setjoingroups` → `Disable`: бот работает только в личных сообщениях.
- Команды задавать не нужно: бот сам вызывает `setMyCommands` при запуске (`/start`, `/new`, `/appeals`, `/digest`, `/code`).

## 3. Telegram Login для веба

- `/setdomain` → `<бот>` → `<домен>` без `https://`. Без этого виджет входа на сайте не появится.
- В `web/.env` при сборке: `VITE_TELEGRAM_BOT_USERNAME=<бот>` без `@`.

## 4. Mini App

1. `/newapp` → `<бот>`.
2. Название `Модус Трейд`, описание `Обращения и предложения сотрудников`.
3. Картинка 640×360: обязательна, подойдёт любой логотип на фоне. GIF пропустите командой `/empty`.
4. Web App URL: `https://<домен>/` — та же сборка веба.
5. Short name, например `app`. Прямая ссылка будет `https://t.me/<бот>/app`. Ссылки на экраны: `https://t.me/<бот>/app?startapp=appeals_21`; формат описан в `web/src/telegram/startParam.ts`.
6. Кнопку меню чата бот ставит сам на `/start`, если задан `MINI_APP_URL`. По желанию можно задать её и для всех: `/setmenubutton` → `<бот>` → `https://<домен>/` → текст `Открыть`.

## 5. Окружение бота на сервере

```
TELEGRAM_BOT_TOKEN=<из шага 1>
BOT_SERVICE_KEY=<тот же, что у бэкенда>
API_BASE_URL=http://api:8000          # адрес бэкенда изнутри docker-сети, или https://<домен>
MINI_APP_URL=https://<домен>
NOTIFICATIONS_POLL_SECONDS=3
```

- `BOT_SERVICE_KEY` — случайная строка, одинаковая у бэкенда и бота: например `openssl rand -hex 32` прямо на сервере, или `secret_generate` в шине.
- Запуск: `docker build -t modus-bot bot && docker run -d --env-file .env --restart unless-stopped modus-bot`, или сервисом в compose рядом с бэкендом. Бот работает через long polling, вебхук и открытый порт не нужны.
- Без токена или ключа бот печатает «Бот не настроен…» и выходит с кодом 2. Это видно в `docker logs`.

## 6. Проверка (T-08)

1. Telegram-аккаунты команды привязаны к ролям сида на сервере. Это настройка вне репозитория, см. SPEC «Сид-данные».
2. `/start` с аккаунта сотрудника: приветствие и меню. С постороннего аккаунта: «Вас пока нет в списке сотрудников» и кнопка «Подать заявку»; ссылка-приглашение `t.me/<бот>?start=inv_<токен>` сразу открывает меню.
3. «Код входа»: шесть цифр. Введите их в мобильном приложении.
4. Кнопка «Открыть»: Mini App открывается без экрана входа, в цветах Telegram. Проверьте на iOS и на Android.
5. Отправьте боту текст: придёт черновик, «Отправить» вернёт номер обращения. Уведомление о назначении придёт ответственному.
