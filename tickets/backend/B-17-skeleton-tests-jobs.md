# B-17: Каркас бэкенда, тестовая обвязка, адаптеры и фоновые задачи

**What to build:** Бэкенд запускается одной командой вместе с базой. Следующие тикеты сразу пишут тесты через HTTP API с управляемым временем, подменяют внешние сервисы и ставят фоновые задачи, не изобретая механизм заново. Идёт параллельно с B-01.

**Blocked by:** None (can start immediately)

**GitHub:** [#2](https://github.com/Blckk699/modus-trade-feedback/issues/2) — статус и обсуждение ведутся там

**Истории из SPEC.md:** —

- [ ] Бэкенд и база запускаются одной командой
- [ ] Тестовая обвязка вызывает HTTP API, управляет текущим временем и содержит один образцовый тест
- [ ] Claude, ElevenLabs, Telegram и Битрикс24 объявлены как адаптеры с подменой в тестах
- [ ] Есть механизм фоновых и периодических задач, которым пользуются эскалация, обработка записей совещаний и рассылка сводки
- [ ] Часовой пояс системы — UTC+5, он задан в настройках
