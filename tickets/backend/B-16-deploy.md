# B-16: Развёртывание на VPS

**What to build:** Бэкенд и база работают на публичном адресе с HTTPS, чтобы Mini App, Telegram Login и мобильное приложение могли к ним подключиться. Клиентские пачки получают адрес и переходят с мока на реальный сервер.

**Blocked by:** B-01 «Каркас, контракт API и мок-сервер»

**Status:** ready-for-agent

**Истории из SPEC.md:** —

- [ ] Сервис доступен по домену с действующим сертификатом
- [ ] Развёртывание выполняется одной командой и описано в инструкции по запуску
- [ ] Ключи Claude, ElevenLabs, Telegram и адрес вебхука Битрикс24 заданы через окружение и не лежат в репозитории
- [ ] На сервере загружены сид-данные
- [ ] Адрес сервера передан остальным пачкам
- [ ] После каждого завершённого тикета бэкенда сервер обновляется, клиенты всегда видят последнюю готовую версию
