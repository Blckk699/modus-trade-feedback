# B-08: Очередь уведомлений для бота и счётчики непрочитанного

**What to build:** Каждое событие, о котором должен узнать пользователь, попадает в очередь уведомлений. Бот забирает их и доставляет в Telegram. В клиентах пользователь видит счётчик непрочитанного.

**Blocked by:** B-05 «Маршрутизация и переназначение»; B-06 «Статусы, решения и приватная переписка»

**Status:** ready-for-agent

**Истории из SPEC.md:** 12, 25, 40, 45

- [ ] Уведомление создаётся при назначении, смене статуса, уточняющем вопросе, ответе автора, шаге эскалации, запросе согласия на показ имени
- [ ] Бот получает неотправленные уведомления и подтверждает доставку; повторной доставки подтверждённого нет
- [ ] Уведомление содержит адресата, текст, ссылку на обращение и действия-кнопки, если они нужны
- [ ] Счётчик непрочитанного доступен клиентам и обнуляется при просмотре
- [ ] Тесты через HTTP API проверяют, какие события порождают уведомления и кому
