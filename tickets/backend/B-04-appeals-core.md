# B-04: Обращение: создание через форму, список, карточка, история

**What to build:** Пользователь создаёт обращение через форму с типом, категорией, приоритетом, текстом, предлагаемым решением и вложениями. Он видит свои обращения, карточку и историю событий. Каждая роль видит ровно те обращения, которые ей положены по матрице доступа.

**Blocked by:** B-03 «Вход через Telegram и роли»

**Status:** ready-for-agent

**Истории из SPEC.md:** 6–11, 17, 42, 59, 63

- [ ] Обращение создаётся с номером и статусом «Новое»
- [ ] К обращению прикладываются файлы и отдаются только тем, кто видит обращение
- [ ] Сотрудник видит только свои обращения, ответственный — назначенные, руководитель — своего подразделения, администратор и собственник — все
- [ ] Список поддерживает фильтры по подразделению, категории, статусу и сроку, включая «просроченные»
- [ ] Каждое изменение обращения попадает в историю событий с автором и временем
- [ ] Тесты через HTTP API проверяют строку «Видеть обращения» матрицы для всех ролей, включая запреты
