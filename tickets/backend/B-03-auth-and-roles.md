# B-03: Вход через Telegram и роли

**What to build:** Сотрудник, которого завёл администратор, входит через Telegram тремя способами: автоматически в Mini App, через Telegram Login в вебе и по одноразовому коду от бота в мобильном приложении. Посторонний войти не может. После входа система знает роль и подразделение пользователя.

**Blocked by:** B-02 «Схема данных и сид-данные»

**Status:** ready-for-agent

**Истории из SPEC.md:** 23, 64, 65

- [ ] Вход по данным Mini App проверяет подпись Telegram и выдаёт сессию
- [ ] Вход через Telegram Login в вебе выдаёт сессию
- [ ] Одноразовый код, выданный боту, обменивается на сессию один раз и истекает по времени
- [ ] Пользователь, которого нет в списке сотрудников или у которого отключён доступ, получает отказ
- [ ] Запрос «кто я» возвращает роль, подразделение и назначения ответственным
- [ ] В тестовом каркасе появился вход под любой ролью одной строкой
- [ ] Тесты через HTTP API покрывают все три способа входа и оба случая отказа
