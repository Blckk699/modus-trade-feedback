# B-12: Режим «совещание»

**What to build:** Руководитель или собственник загружает аудиозапись встречи. Система расшифровывает её и предлагает черновики обращений, у каждого есть цитата из расшифровки. Загрузивший подтверждает, правит или отбрасывает каждый черновик и может указать сотрудника как автора.

**Blocked by:** B-05 «Маршрутизация и переназначение»; B-09 «Черновик обращения из текста и голоса»

**GitHub:** [#41](https://github.com/Blckk699/modus-trade-feedback/issues/41) — статус и обсуждение ведутся там

**Истории из SPEC.md:** 48–51, 62

- [ ] Загрузить запись могут только руководитель и собственник
- [ ] После обработки доступны расшифровка и список черновиков с типом, категорией, сутью и цитатой
- [ ] Подтверждённый черновик создаёт обращение с источником «совещание» и идёт по обычной маршрутизации
- [ ] Отброшенный черновик обращения не создаёт; без подтверждения не создаётся ничего
- [ ] Автором обращения можно указать любого сотрудника, иначе автор — загрузивший
- [ ] Обработка длинной записи не блокирует запрос: клиент видит состояние «обрабатывается»
- [ ] В тестах расшифровка и извлечение подменены на границе адаптеров
