# B-13: Сводка и аналитика

**What to build:** Собственник и руководители получают сводку: новое за сутки, зависшее, закрытое за неделю, повторяющиеся темы. В клиентах есть экран с количеством обращений по типам и категориям, долей закрытых, средним временем первого ответа и списком просроченных. Сводка уходит в бот в 9:00 и по запросу.

**Blocked by:** B-07 «Сроки первого ответа и эскалация»; B-08 «Очередь уведомлений для бота и счётчики непрочитанного»; B-10 «Поиск и склейка повторов»

**Status:** ready-for-agent

**Истории из SPEC.md:** 52–58, 61

- [ ] Данные сводки отдаются по компании для собственника и по подразделению для руководителя
- [ ] Метрики поддерживают фильтр по подразделению, категории, статусу и сроку
- [ ] Список зависших содержит обращение, ответственного и число дней просрочки
- [ ] Повторяющиеся темы строятся по счётчикам склеенных обращений
- [ ] Текст сводки для бота формируется по запросу и ежедневно в 9:00 попадает в очередь уведомлений
- [ ] Числа на сид-данных совпадают с посчитанными вручную, это закреплено тестом
