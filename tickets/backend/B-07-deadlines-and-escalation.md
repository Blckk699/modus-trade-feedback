# B-07: Сроки первого ответа и эскалация

**What to build:** У каждого обращения есть срок первого ответа в рабочих днях по приоритету. Если ответственный молчит, система сама напоминает ему, через рабочий день уведомляет руководителя подразделения, ещё через день помечает обращение как зависшее для сводки собственника.

**Blocked by:** B-05 «Маршрутизация и переназначение»; B-06 «Статусы, решения и приватная переписка»; B-08 «Очередь уведомлений для бота и счётчики непрочитанного»

**Status:** ready-for-agent

**Истории из SPEC.md:** 27, 40, 45, 57

- [ ] Срок считается в рабочих днях: высокий — 1, средний — 3, низкий — 5, значения берутся из настроек
- [ ] Пока обращение ожидает уточнения от автора, отсчёт приостановлен
- [ ] При переназначении срок отсчитывается заново
- [ ] Фоновая задача выполняет три шага эскалации с интервалом в рабочий день и не повторяет уже сделанный шаг
- [ ] Положительные отзывы не имеют срока и не эскалируются
- [ ] Тесты управляют временем явно и проверяют расчёт срока, приостановку и каждый шаг эскалации
