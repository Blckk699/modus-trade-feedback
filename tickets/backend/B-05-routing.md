# B-05: Маршрутизация и переназначение

**What to build:** Новое обращение само попадает к ответственному по правилу категории. Если он отмечен отсутствующим, обращение получает заместитель. Если нет обоих или категория не определена, обращение попадает в очередь администратора. Вместе с ответственным обращению назначается срок первого ответа. Руководитель, администратор и собственник могут переназначить ответственного с причиной.

**Blocked by:** B-04 «Обращение: создание через форму, список, карточка, история»

**GitHub:** [#26](https://github.com/Blckk699/modus-trade-feedback/issues/26) — статус и обсуждение ведутся там

**Истории из SPEC.md:** 9, 27, 44, 68, 70

- [ ] При создании обращению назначается ответственный категории
- [ ] Вместе с ответственным назначается срок первого ответа в рабочих днях по приоритету из настроек: высокий — 1, средний — 3, низкий — 5; рабочие дни — понедельник–пятница по UTC+5
- [ ] При переназначении срок отсчитывается заново
- [ ] При отсутствии ответственного назначается заместитель
- [ ] При отсутствии обоих обращение видно в очереди нераспределённых у администратора
- [ ] Переназначение требует причину и записывается в историю
- [ ] Сотрудник и ответственный переназначить не могут
- [ ] Тесты через HTTP API покрывают все три ветки маршрутизации и права на переназначение
