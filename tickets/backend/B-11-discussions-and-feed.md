# B-11: Общие обсуждения и лента реализованного

**What to build:** Ответственный или руководитель выносит обращение на общее обсуждение с публичной формулировкой и сроком. Автор решает, показывать ли его имя. Все сотрудники голосуют «за» или «против» и комментируют. Руководитель фиксирует итог. Реализованные обращения попадают в общую ленту.

**Blocked by:** B-06 «Статусы, решения и приватная переписка»; B-08 «Очередь уведомлений для бота и счётчики непрочитанного»

**Status:** ready-for-agent

**Истории из SPEC.md:** 18, 20–22, 38, 47

- [ ] До выноса обращение не видно никому, кроме участников по матрице доступа
- [ ] При выносе автору уходит запрос на показ имени; без согласия в ленте стоит только подразделение
- [ ] Каждый пользователь голосует один раз и может изменить голос до окончания срока
- [ ] Публичные комментарии хранятся отдельно от приватной переписки, приватная переписка в обсуждении не видна
- [ ] Итог обсуждения фиксирует руководитель или собственник, итог записывается в обращение
- [ ] Обращение в статусе «Реализовано» появляется в ленте реализованного с публичной формулировкой результата
- [ ] Тесты через HTTP API проверяют видимость до и после выноса и показ имени только с согласия
