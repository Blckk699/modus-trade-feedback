# B-06: Статусы, решения и приватная переписка

**What to build:** Ответственный ведёт обращение по жизненному циклу из спеки: берёт на рассмотрение, задаёт автору уточняющий вопрос, принимает в работу, отклоняет с причиной, фиксирует результат, принимает положительный отзыв. Автор отвечает на вопрос в приватной переписке и видит итог.

**Blocked by:** B-04 «Обращение: создание через форму, список, карточка, история»

**Status:** ready-for-agent

**Истории из SPEC.md:** 13–16, 28–33, 46, 60

- [ ] Разрешены только переходы из диаграммы статусов спеки, остальные возвращают ошибку
- [ ] Отклонение без текста причины и «Реализовано» без текста результата невозможны
- [ ] Уточняющий вопрос переводит обращение в «Ожидает уточнения», ответ автора возвращает в «На рассмотрении»
- [ ] Положительный отзыв закрывается одним действием «Принято»
- [ ] Приватную переписку видят автор, ответственный, руководитель подразделения и собственник; администратор не видит
- [ ] Первый ответ ответственного фиксирует время первого ответа
- [ ] Тесты через HTTP API покрывают разрешённые и запрещённые переходы и права на переписку
