# W-01: Каркас веба, клиент API и вход через Telegram Login

**What to build:** Пользователь открывает веб-приложение, входит через Telegram Login и попадает на стартовый экран своей роли. Интерфейс адаптивный: те же экраны открываются в Mini App на ширине телефона. Приложение работает на мок-сервере по контракту.
