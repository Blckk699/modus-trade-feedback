# W-01: Каркас веба, клиент API и вход через Telegram Login

**What to build:** Пользователь открывает веб-приложение, входит через Telegram Login и попадает на стартовый экран своей роли. Интерфейс адаптивный: те же экраны открываются в Mini App на ширине телефона. Приложение работает на мок-сервере по контракту.

**Blocked by:** B-01 «Каркас, контракт API и мок-сервер»

**Status:** ready-for-agent

**Истории из SPEC.md:** 23, 24

- [ ] Клиент API сгенерирован из контракта
- [ ] Вход через Telegram Login работает, неавторизованный видит экран входа
- [ ] Навигация зависит от роли: сотрудник видит «Мои обращения» и ленту, руководитель и собственник — ещё сводку и обработку, администратор — настройки
- [ ] Вёрстка работает на ширине телефона и на десктопе, в светлой и тёмной теме
- [ ] Способ входа вынесен в отдельный модуль, чтобы пачка Telegram подключила вход Mini App без правки экранов
