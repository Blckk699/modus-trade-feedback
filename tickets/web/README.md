## Общие правила для всех пачек

- Источник истины — `SPEC.md` в корне рабочей папки. Тикет не повторяет спеку, а ссылается на номера историй.
- Контракт API ведёт пачка бэкенда (тикет B-01). Клиенты не меняют контракт сами: расхождение передаётся владельцу бэкенда.
- До готовности бэкенда клиенты работают на мок-сервере из контракта. Переход на реальный сервер происходит в последнем тикете пачки.
- Вся бизнес-логика живёт в бэкенде. Клиент не дублирует правила прав, сроков и маршрутизации, а скрывает недоступные действия по данным API.
- В продукте не должно быть заглушек: функция либо работает целиком, либо её нет в интерфейсе.
- Интерфейс только на русском. Данные только синтетические.
- Срок сдачи: пятница, 13 ноября, 14:00. Заморозка изменений: четверг вечером.
