# T-06: Оболочка Mini App

**What to build:** Сотрудник открывает Mini App из бота и сразу оказывается внутри без экрана входа. Приложение выглядит как часть Telegram: тема, кнопка «Назад», главная кнопка. Ссылка из уведомления открывает нужное обращение.

**Blocked by:** T-01 «Каркас бота, привязка сотрудника и код входа»; W-01 «Каркас веба, клиент API и вход через Telegram Login»

**Status:** ready-for-agent

**Истории из SPEC.md:** 23, 24

- [ ] Вход в Mini App выполняется автоматически по данным Telegram через модуль входа веб-приложения
- [ ] Цвета следуют теме Telegram, кнопка «Назад» Telegram управляет навигацией
- [ ] Ссылка из уведомления открывает карточку конкретного обращения
- [ ] Ссылка из сводки открывает экран аналитики
- [ ] Изменения ограничены модулем входа и оболочкой; экраны остаются за пачкой фронта
- [ ] Mini App открывается на iOS и Android
