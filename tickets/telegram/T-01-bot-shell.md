# T-01: Каркас бота, привязка сотрудника и код входа

**What to build:** Сотрудник запускает бота, бот узнаёт его по списку сотрудников и показывает меню. Посторонний получает вежливый отказ. По команде бот выдаёт одноразовый код для входа в мобильное приложение.

**Blocked by:** B-01 «Контракт API и мок-сервер»
