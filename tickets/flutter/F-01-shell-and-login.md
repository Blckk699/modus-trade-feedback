# F-01: Каркас приложения, клиент API и вход по коду из бота

**What to build:** Пользователь открывает мобильное приложение, вводит одноразовый код от бота и попадает на стартовый экран своей роли. Приложение работает на мок-сервере по контракту.

**Blocked by:** B-01 «Контракт API и мок-сервер»

**GitHub:** [#5](https://github.com/Blckk699/modus-trade-feedback/issues/5) — статус и обсуждение ведутся там

**Истории из SPEC.md:** 23, 24

- [ ] Клиент API сгенерирован из контракта
- [ ] Экран входа принимает одноразовый код и объясняет, как получить его в боте
- [ ] На моке и локально доступен dev-вход с выбором пользователя
- [ ] Сессия сохраняется между запусками, есть выход
- [ ] Навигация зависит от роли так же, как в вебе
- [ ] Приложение собирается под Android и iOS
- [ ] Адрес сервера задаётся настройкой: мок или реальный
